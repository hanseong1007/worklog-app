## 화면 구성

**본부장(`chief`)·대표(`ceo`) 계정은 일지 작성 화면이 아니라 전자결재함이 첫 화면입니다.** 로그인하면 팝업을 열지 않아도 화면 자체가 `경덕농수산 전자결재` 화면으로 바뀝니다(아래 '전자결재 — 결재자 전용 화면' 참고). 담당(`staff`)·관리자(`admin`) 계정은 아래 일지 작성 화면 그대로입니다.

상단 오른쪽 **🖨️(기간 인쇄)** 버튼은 모든 계정에 있고, 검색 기간과 담당자를 골라 일지를 한꺼번에 인쇄·PDF 저장합니다(`README` 아래 '일괄 인쇄 · PDF' 참고). 폭이 좁은 휴대폰에서는 아이콘으로만 보입니다.

| 영역 | 내용 |
|---|---|
| 일자 | 날짜를 고르면 옆에 요일(금요일)이 자동으로 붙고, 인쇄에는 `2026-11-20(금)`으로 나옵니다. ‹ › 로 하루씩 이동, `오늘` 버튼. |
| 결재란 이름 | 담당자·본부장·대표이사 이름 입력. 새 기기·새 계정·초기화 상태에서는 본부장 **`박복심`**, 대표이사 **`고경덕`** 이 기본으로 들어가고, 직접 고친 이름은 그대로 유지됩니다. 입력한 이름이 **전자결재 결재선**과 인쇄 결재란에 그대로 들어갑니다. 담당자는 성명을 따라갑니다. |
| 기본 정보 | 소속(기본 `물류팀`), 성명(기본 `박한성`), 출근·퇴근 시각(기본 08:30·17:30). **근무시간 자동 계산** + `휴게 1시간 차감` 스위치(자정을 넘겨도 계산). |
| 오늘의 업무 | **한 줄 = 업무명 1개 + 업무내용 1개**입니다. 업무명 칸 아래 업무내용 칸이 한 쌍으로 붙고, 업무내용 칸에서 **Enter**를 누르면 다음 업무 줄이 생깁니다. `+ 업무 추가`로 줄을 늘리고 줄 끝 `×`로 지웁니다. `+출고준비 및 배송(진열)`, `+차량정비` 빠른 칩과 칩 끝의 `+ 업무명 추가`로 자주 쓰는 업무명을 만들 수 있습니다(`항목 편집`으로 삭제). **업무내용 프리셋** — `항목 편집` 중에 칩을 누르면 그 업무의 업무내용을 미리 등록·삭제할 수 있고, 등록된 칩을 누르면 **업무내용 선택 창**이 열려 여러 개를 고를 수 있습니다(고른 업무내용을 **각각 한 줄씩** 넣거나 **한 줄로 합쳐서** 넣기 — 창 안에서 고릅니다). |
| 반품사항 | 반품내역·원인 및 조치 행 추가/삭제. |
| 법인카드 | 사용금액(입력하면 `12,300`처럼 천 단위 쉼표) · 사용내역, **합계 자동 표시**. 인쇄에는 합계가 사용금액 칸 아래 작게 들어갑니다. |
| 기타 | 거래처 현금수금 내역 등 넓은 입력란. |

업무명과 업무내용은 **미리보기·A4 인쇄 표에서 `업무명 | 업무내용` 한 줄에 하나씩** 들어갑니다(빈 줄 포함 기본 9행, 내용이 많으면 자동으로 늘어납니다). 보고 복사는 `1. 업무명: 업무내용`, 구글 시트 상신도 업무 칸에 `업무명: 업무내용` 한 줄씩 들어갑니다.
예전에 한 업무명 아래 `- 항목1`, `- 항목2`로 묶여 저장된 일지·백업은 불러올 때 **업무명이 같은 여러 줄로 자동으로 펼쳐집니다**.

### 업무명 · 업무내용 프리셋

- `오늘의 업무` 위 칩은 **업무명**이고, 업무명마다 **업무내용**을 여러 개 등록해 둘 수 있습니다(업무명 12개, 업무내용 30개까지).
- 등록은 `항목 편집` → 칩을 누르면 열리는 **업무내용 관리** 창에서 추가·삭제합니다.
- 등록된 칩을 누르면 **업무내용 선택** 창이 열립니다. 체크박스로 여러 개(또는 `모두 선택`) 고르고 `일지에 추가`를 누르면 일지에 들어갑니다.
- 넣는 방식은 창 안의 **`각각 한 줄씩` / `한 줄로 합치기`** 두 버튼으로 고릅니다. `각각 한 줄씩`은 고른 업무내용마다 `업무명 + 업무내용` **한 줄씩**(예: 업무명 · 업무내용1 / 업무명 · 업무내용2), `한 줄로 합치기`는 업무명 **한 줄**에 고른 내용을 **` / `로 이어 붙입니다**(예: 업무명 · 업무내용1 / 업무내용2). 고른 개수와 결과 모양은 창 아래 미리보기와 추가 버튼 문구(`업무내용 2줄 일지에 추가` / `업무내용 2개 한 줄로 추가`)로 바로 확인됩니다.
- 마지막에 고른 방식은 계정별로 기억해 두어 다음에 창을 열 때 그대로 선택되어 있습니다(처음 쓰는 계정은 기존과 같은 `각각 한 줄씩`).
- `한 줄로 합치기`로 넣은 줄도 보통 줄과 똑같이 다뤄집니다 — A4 인쇄·PDF, 카톡 보고 복사(`업무명: 업무내용1 / 업무내용2`), 구글 시트 결재 상신과 다시 불러오기에서 그대로 유지됩니다. 같은 업무명의 업무내용 칸에서 직접 고쳐도 됩니다.
- 업무내용을 하나도 고르지 않으면 방식과 상관없이 **업무명만** 들어간 한 줄이 추가됩니다.
- 이미 같은 **(업무명, 업무내용) 쌍**이 일지에 있으면 그 줄은 건너뛰고 몇 개를 건너뛰었는지 알려 줍니다. 업무내용이 하나도 등록되지 않은 칩을 누르면 업무명만 들어간 한 줄이 추가되고, 같은 업무명 줄이 이미 있으면 빈 줄을 만들지 않고 알려 줍니다.
- 프리셋은 계정별로 암호화해 저장되어 기기를 바꿔도 초대 링크로 이어집니다. 예전에 업무명만 저장해 둔 계정은 업무내용 없이 그대로 살아납니다.

## 전자결재 — 실시간 결재(구글 시트) 한 가지 방식

업무일지 화면의 **전자결재** 카드에 `담당 / 본부장 / 대표` 세 칸의 상태가 보이고, `실시간 결재 열기`(결재함·관리자 설정)와 `결재 상신` 버튼만 있습니다.

### 결재자 전용 화면 (본부장·대표)

- **로그인하면 바로 전자결재함**입니다. 팝업(모달)이 아니라 화면 전체가 결재함이라 닫기 버튼이 없습니다.
  - 작성용 UI(상단 `목록`/`미리보기`, 날짜 이동 바, `결재란 이름`, `기본 정보`, `오늘의 업무`, `반품·교환`, `법인카드`, `특이사항`, 하단 `저장`/`보고 복사`/`인쇄·PDF`)와 작성자용 `결재 상신` 버튼·`작성중` 뱃지는 보이지 않습니다.
  - 상단에는 앱 이름 `경덕농수산 전자결재`와 `내 계정` 프로필 원형 버튼(비밀번호 변경·로그아웃)이 그대로 있습니다. 작성용 `목록`/`미리보기`는 숨기고 **🖨️(기간 인쇄)** 는 남습니다.
  - 결재함 제목 옆에 **대기 건수 뱃지**, 아래에 `내가 결재할 문서 N건 · 결재함 전체 M건` 안내와 `결재함 새로고침`·**`🖨️ 기간별 인쇄`** 버튼이 있습니다.
  - 본부장이 승인하면 그 자리에서 `📩 대표님께 알리기`가 뜨고, 승인·반려하는 즉시 대기 건수가 줄어듭니다.
- 담당(`staff`)·관리자(`admin`)는 기존대로 일지 작성 화면에서 `실시간 결재 열기`로 결재함을 엽니다.

### 결재함 카드의 문서 내용 보기

결재함 카드에서 결재할 문서의 내용을 그대로 읽고 승인·반려할 수 있습니다. 시트(`list`)가 내려주는 값을 씁니다.

| 표시 | 내용 |
|---|---|
| 소속 · 근무시간 | 신청한 일지의 `소속`, `근무시간` (있을 때만 · 시각이 붙어 있으면 `8시간`만) |
| 오늘의 업무 | `업무명: 업무내용` 줄바꿈 그대로 |
| 반품·교환 | 반품 내역·조치 (있을 때만) |
| 법인카드 지출 | 합계가 0원보다 클 때만 `12,500원` 처럼 |
| 특이사항 | 거래처 현금수금 등 기타 (있을 때만) |

- 모두 비어 있으면 `(입력된 업무 내용 없음)`으로 알려 줍니다.
- **내가 지금 결재할 차례인 카드**(본부장이면 `본부장 대기`, 대표면 `대표 대기`)는 내용이 **기본으로 펼쳐져** 바로 읽고 승인·반려할 수 있고, 끝난 카드·다른 단계 카드는 `내용 보기` 버튼으로 접었다 펼 수 있습니다(내 대기 카드도 접을 수 있습니다).

### 결재 3단계

| 단계 | 하는 일 |
|---|---|
| 담당(작성자) | **상신할 때 자동으로 승인**됩니다(상신일시 = 담당 결재일시). |
| 본부장 | 결재함에서 **본부장 권한 계정**이 `본부장 승인`/`본부장 반려`. |
| 대표 | **본부장 승인 뒤에** **대표 권한 계정**이 `대표 승인`/`대표 반려`. |

- 한 단계라도 반려되면 그 결재는 반려로 끝나고 사유가 카드와 결재함에 남습니다. 결재란(A4)에는 단계별 `이름 승인`/`반려`가 찍힙니다.
- **승인·반려는 로그인한 계정의 결재 권한에서만 됩니다.** 결재함 위에는 내 권한이 그대로 표시됩니다(관리자만 역할 전환).

| 계정 결재 권한 | 결재함에서 할 수 있는 일 |
|---|---|
| 담당(`staff`, 기본) | 상신 · 결재함 새로고침 · 목록 조회만. 승인·반려 버튼 없음(안내 문구 표시) |
| 본부장(`chief`) | 본부장으로 고정. `본부장 대기` 건에만 `본부장 승인`/`본부장 반려` |
| 대표(`ceo`) | 대표로 고정. `본부장 승인 완료 · 대표 대기` 건에만 `대표 승인`/`대표 반려` |
| 관리자(`admin`, `all`) | 본부장/대표를 골라 테스트·대리 결재(기존과 동일) |

- 승인 결과는 구글 시트에 바로 기록되고, 이 기기의 그 일지(상신할 때 받은 결재번호)에도 반영되어 카드·A4 결재란이 함께 바뀝니다.
- **다른 기기·다른 브라우저에서도 결재 상태가 그대로 보입니다.** 앱을 열면(로그인·새로고침·앱으로 돌아올 때·날짜 이동) 결재함 목록을 조용히 한 번 받아, 이 기기 일지에 결재번호가 없더라도 **같은 날짜(`YYYY-MM-DD`)·같은 성명**으로 올라간 건(가장 최신 건)이 있으면 그 결재번호와 상태(담당 승인, 본부장·대표 대기/승인/반려, 결재자·일시)를 자동으로 붙입니다. 일지 내용(업무·금액)은 시트에서 가져오지 않고 결재 상태만 맞춥니다.
  - 그래서 휴대폰에서 상신한 일지를 PC에서 열어도 `담당 승인 · 본부장 대기`와 `📩 본부장님께 알리기`가 바로 보입니다. 날짜가 다르거나 작성자(성명)가 다르면 붙이지 않습니다.
  - 자동으로 붙은 일지는 이미 상신된 일지라 `결재 상신`을 눌러도 시트에 한 줄 더 쌓이지 않고 `이미 결재 올린 일지입니다.` 안내가 나옵니다(반려된 일지는 수정 후 다시 상신 가능). 담당(`staff`) 계정도 이 조용한 조회를 하며, 빨간 배지만 달지 않습니다.
- **중복 상신을 막습니다.** 상신 중에는 버튼이 `상신 중…`으로 잠겨 연타해도 시트에는 한 줄만 쌓이고, 이미 `결재대기`·`승인`인 일지는 다시 상신되지 않고 `이미 결재 올린 일지입니다. 결재함에서 진행 상태를 확인하세요.` 안내가 나옵니다(반려된 일지는 수정 후 다시 상신 가능). 결재함에 같은 날짜·같은 작성자의 `결재대기` 건이 있으면 한 번 확인창을 띄웁니다.

### 결재 알리기(카톡·문자) · `결재 대기 N건` 배지

- **알리기 버튼** — 상신·승인이 끝나면 다음 결재자에게 바로 알릴 수 있습니다. 누르면 휴대폰의 공유 창(`navigator.share`)이 열려 **카카오톡·문자**를 고를 수 있고, 공유 창이 없는 PC·브라우저에서는 문구가 복사되며 토스트로 안내합니다(카톡·문자에 붙여넣기).
  - 담당이 `결재 상신`에 성공하면 전자결재 카드와 결재함 위에 **`📩 본부장님께 알리기`** — `[경덕농수산 업무일지] {성명}({소속}) {일자} 업무일지 결재 요청드립니다.` + `확인: https://hanseong1007.github.io/worklog-app/`
  - 본부장이 승인하면 결재함 위에 **`📩 대표님께 알리기`** — `… 본부장 승인 완료, 대표님 결재 요청드립니다.` + 확인 링크
  - 결재함의 `본부장 대기`·`대표 대기` 카드에는 작은 **`📩 알리기`** 버튼이 함께 있어 나중에도 다시 알릴 수 있습니다.
- **`결재 대기 N건` 빨간 배지** — 로그인 직후(그리고 앱으로 다시 돌아올 때) 결재함 목록을 조용히 한 번 받아 내가 결재할 건수를 셉니다. 받지 못해도 팝업 없이 넘어갑니다.
  - 본부장 `N` = `본부장 대기`, 대표 `N` = `본부장 승인 완료 · 대표 대기`, 관리자 `N` = 대기 중 전체, 담당은 배지 없음(담당도 결재 상태 동기화를 위해 목록은 조용히 받습니다).
  - `실시간 결재 열기` 버튼과 전자결재 제목 옆에 **빨간 배지**로 표시되고, 결재함에서 승인·반려하면 즉시 줄어들며 0건이면 사라집니다.

### 시트에 쌓이는 내용

- `업무일지결재` 시트에 한 줄씩 쌓입니다. 기존 14개 열은 그대로 두고 뒤에 6개 열을 덧붙입니다(지난 줄은 건드리지 않음).

| A~J | K | L·M·N | O·P·Q | R·S·T |
|---|---|---|---|---|
| 결재번호 · 상신일시 · 일자 · 소속 · 성명 · 근무시간 · 업무 · 반품 · 법인카드합계 · 기타 | 상태(전체) | 결재자(마지막) · 결재일시 · 반려사유 | 본부장상태 · 본부장결재자 · 본부장결재일시 | 대표상태 · 대표결재자 · 대표결재일시 |

- 업무 칸은 `업무명: 업무내용` 한 줄씩(업무 한 줄 = 한 쌍), 반품·기타는 한 칸에 줄바꿈으로 들어갑니다.
- **근무시간(F) 칸**은 출퇴근 시각까지 함께 적습니다 — `08:30~17:30 · 8시간`. 앱은 이 칸에서 시각을 꺼내 **출근시각·퇴근시각 칸을 되살립니다**(목록에서 열거나 기간 인쇄할 때). 시각 없이 `8시간`만 적힌 옛 줄은 시각을 지어내지 않고 **빈 칸으로 둡니다**. (시각을 넣으려면 그 칸을 `08:30~17:30 · 8시간` 꼴로 직접 고쳐도 됩니다.)
- 업무 칸을 읽을 때는 **`업무명: 업무내용` 한 줄**과 **`업무명` 아래 `- 업무내용`** 두 모양을 모두 알아보고 `업무명`/`업무내용` 두 칸으로 나눕니다(`10:30` 같은 시각의 콜론은 나누지 않음).
- 예전 형식(상태 한 칸만 있던 시절)의 줄이 남아 있어도 앱이 3단계로 풀어서 보여 주고, 예전 앱이 새 줄을 읽어도 깨지지 않습니다.

## 로그인 · 암호화

- 앱을 열면 **로그인 화면**이 먼저 나옵니다. 아이디·비밀번호를 넣어야 일지가 열립니다.
- 관리자 기본 계정은 `admin` / `admin1234` 입니다. 처음 로그인하면 오른쪽 위 **계정 동그라미 → 내 계정 → 내 비밀번호 바꾸기**로 바로 바꿔 쓰세요. (로그인 화면에는 아이디·비밀번호 안내를 일부러 넣지 않았습니다.)
- **예시 일지는 소스에 평문으로 남지 않습니다.** `scripts/worklog_crypto.py`가 만든 암호문(`SEED_DATA`)만 `index.html`에 들어가고, 로그인으로 열쇠를 풀어야 2025-02-14 예시가 메모리에 올라옵니다(순수 JS SHA-256 키스트림, 외부 라이브러리 없음).
- **저장되는 일지도 암호문**입니다. 브라우저 저장소(localStorage)를 열어도 업무·거래처·금액이 글자로 보이지 않습니다. 열쇠는 로그인한 사람의 비밀번호(salt+hash)로 감싸 보관하고, 비밀번호를 바꾸면 새 비밀번호로 다시 감쌉니다.
- **오늘의 업무 업무명·업무내용 프리셋도 계정별로 암호화해 저장**합니다(`kdw.u.<아이디>.taskchips.v1`). 새 계정은 기본 두 업무명(`출고준비 및 배송(진열)`, `차량정비`, 업무내용은 빈 상태)으로 시작하고, 업무명은 12개까지 만들 수 있습니다.
- 검색 엔진에는 잡히지 않도록 `<meta name="robots" content="noindex, nofollow">`를 넣었습니다.

### 사용자 관리 · 초대 링크 (관리자)

- **내 계정 → 사용자 관리**에서 직원 계정(아이디·이름·처음 비밀번호·**결재 권한**)을 만들고 **초대 링크 복사**를 눌러 카톡으로 보냅니다. 결재 권한은 `담당(상신만 가능)`/`본부장`/`대표` 중에 고르고, 목록에서 바로 바꿀 수 있습니다(관리자는 `전체` 고정).
- 링크(`#invite=...`)를 연 직원 휴대폰에는 **그 직원 계정만** 생기고 `admin` 계정은 만들어지지 않습니다. 그 기기에서는 직원이 자기 아이디로 로그인해 **자기 일지만** 봅니다.
- 링크에는 계정 정보(비밀번호는 해시, 일지 열쇠는 그 직원 비밀번호로 감싼 값)와 **그 직원의 결재 권한**이 함께 들어 있습니다. 이미 그 계정이 있는 기기에서 새 링크를 열면 권한이 새 값으로 맞춰집니다(비밀번호는 그대로). 그러니 그 직원에게만 보내세요. `admin` 계정은 링크에 담기지 않습니다.
- 직원 비밀번호를 잊으면 관리자가 **비밀번호 재설정**으로 새로 정해 줄 수 있습니다. 계정 삭제 시 그 기기의 그 직원 일지도 함께 지워집니다.
- 결재 권한이 없는(예전에 만들어진) 계정은 자동으로 `담당`, `admin`은 `전체`로 동작합니다. 통합 로그인 포털로 들어와도 같습니다.

## 저장과 백업

- 입력하는 대로 **이 브라우저에 암호화해 자동 저장**됩니다(날짜별·계정별). 상단 `저장됨 · 23:15` 표시로 확인.
- `목록`에서 날짜별 일지를 열거나 삭제할 수 있고, `이전 일지 복사`로 가장 최근 앞 일지의 업무·반품·법인카드·기타를 날짜·출퇴근·결재란은 그대로 둔 채 가져옵니다(업무명·업무내용 1쌍 그대로).
- `목록 → 백업 저장`은 전체 일지를 JSON 파일로 내려받고, `백업 불러오기`로 되돌립니다. 예전 `{name, content}`·`items:[…]` 형식 백업도 1줄 1쌍으로 펼쳐서 열립니다. 백업 파일은 **평문**이니 보관에 주의하세요. **브라우저 데이터를 지우면 저장 내용이 사라지므로** 가끔 백업해 두세요.
- 저장은 기기·브라우저·계정마다 따로입니다(서버 공유 없음).

## 인쇄 · PDF

- 아래 `인쇄 · PDF` 버튼(또는 `미리보기` 안의 인쇄 버튼) → 인쇄 대화상자에서 **대상: PDF로 저장**.
- 인쇄 설정은 **용지 A4, 여백 없음(None), 배율 100%(기본)** 로 두면 종이 서식 그대로 **정확히 1장**에 나옵니다.
- 내용이 아주 많으면 글자·줄 높이가 자동으로 줄어 1장에 맞춰지고, 그래도 넘치면 2장으로 이어집니다.
- 한 건씩이 아니라 **기간·담당자별로 여러 장을 한 번에** 인쇄하려면 아래 '일괄 인쇄 · PDF'를 씁니다.

### 일괄 인쇄 · PDF (기간·담당자별)

상단의 **🖨️(기간 인쇄)** 버튼으로 엽니다. 본부장(`chief`)·대표(`ceo`)는 결재 전용 화면에서도 상단 같은 버튼과 결재함 제목 아래 **`🖨️ 기간별 인쇄`** 버튼으로, 누구나 `목록`(저장된 업무일지) 시트의 **`🖨️ 기간·담당자별 인쇄`** 버튼으로도 열 수 있습니다. 모든 권한이 씁니다.

- **검색 기간** — 시작일 ~ 종료일(`YYYY-MM-DD`). `오늘` · `이번 주`(월요일 시작) · `이번 달` · `지난 달` 빠른 선택 버튼.
- **담당자** —
  - 담당(`staff`) 계정: `내 일지 · 이름` 하나로 잠깁니다. 다른 사람 일지는 목록에도 선택지에도 나오지 않습니다(선택 값을 바꿔도 서버 쪽 필터가 막습니다).
  - `admin` · 이름이 `박한성` · 본부장 · 대표: **`전체 담당자 (전체 자료)`** 또는 한 사람을 골라 그 기간의 일지를 한꺼번에 인쇄합니다. 선택지는 시트에 올라온 작성자 + 등록 계정 이름을 중복 없이 합쳐 만듭니다.
- **자료** — 결재함 시트(`list`)에서 최근 결재를 받아(최대 60건) 기간·담당자로 거르고, 이 기기에 저장된 일지도 함께 넣습니다. 같은 날짜·같은 담당자는 한 건으로 보며, 이 기기 원본이 있으면 손으로 그린 서명과 법인카드 사용내역까지 **원본 그대로** 씁니다. 시트에만 있는 다른 담당자 일지는 시트의 업무·반품·법인카드 합계·기타와 결재 상태(담당 승인, 본부장·대표 승인/반려)로 서식을 다시 만듭니다.
- **목록** — 날짜·담당자·결재 상태·출처(`이 기기`/`시트`)·소속·근무시간과 맨 위에 **`선택 N건 / 전체 M건 · A4 N장`**.
- **체크해서 인쇄** — 목록의 **행마다 체크박스**가 있고(줄 아무 곳이나 눌러도 선택/해제), 건수 옆 **`전체 선택`/`전체 해제`** 체크박스로 한 번에 바꿉니다. 기간·담당자를 바꾸거나 `새로고침`하면 **검색된 항목이 전부 체크된 상태**로 시작하고, 하나씩 끄면 선택 건수와 A4 장수가 바로 줄어듭니다(일부만 체크되면 전체 선택 칸이 중간 표시). 미리보기를 닫아도 체크는 그대로 남습니다.
- `선택 N건 인쇄 · PDF` → **체크한 일지만** 이어 붙인 **미리보기**. **일지 1건당 A4 1장**(`page-break-after: always`, 마지막 장 제외)이며, 미리보기의 `인쇄 · PDF`로 한 번에 인쇄하거나 PDF로 저장합니다(PC 브라우저 PDF 저장·Android 인쇄 모두 같은 `window.print()`).
- 기간에 일지가 없으면 버튼이 잠기고 `이 기간에 인쇄할 업무일지가 없습니다`, 하나도 체크하지 않으면 버튼이 잠기고 `인쇄할 일지를 체크해 주세요`로 알려 줍니다.
- 시트는 최근 60건까지만 내려 주므로 그보다 오래된 기간은 화면 안내대로 시트에서 직접 확인해야 합니다.

## 목록 — 다른 기기에서 쓴 일지까지

`≡ 목록`(저장된 업무일지)은 **이 기기에 저장된 일지 + 구글 시트(결재함)에 올라온 일지**를 날짜·작성자로 묶어 함께 보여 줍니다. PC에서 상신하고 스마트폰에서 열어도 그 일지가 목록에 나옵니다.

- 열 때마다 시트에서 최근 결재를 받아 오고, 위쪽 **`☁️ 시트에서 불러오기`** 버튼으로 다시 부를 수 있습니다(불러오는 중·몇 건을 받았는지 안내).
- **같은 날짜·같은 담당자**는 한 줄이며, 이 기기 원본이 있으면 원본을 쓰고 결재 상태만 시트 기준으로 맞춥니다. 시트에만 있는 일지는 **`시트` 배지**로 표시합니다.
- **권한** — 담당(`staff`)은 **내 이름으로 상신한 일지**만 모읍니다. `admin`·`박한성`·본부장·대표는 직원 전체 일지를 **작성자 이름·결재 상태 배지**와 함께 봅니다.
- **클릭하면 작성 화면으로 불러옵니다** — 날짜·소속·성명·근무시간·업무명/업무내용·반품·법인카드·특이사항·결재 상태가 그대로 채워져 바로 보고 고치거나 인쇄할 수 있습니다(고친 뒤 저장하면 이 기기에도 남습니다). 근무시간 칸에 시각(`08:30~17:30 · 8시간`)이 있으면 출근·퇴근 시각까지 채워지고, 시각이 없던 옛 줄은 빈 칸으로 둡니다. 시트 일지에는 `삭제` 버튼이 없습니다(시트에서 지워야 함).
- 시트가 안 되면 이 기기 일지만 보여 주고 안내를 띄우며, 기간 인쇄·단건 인쇄와 충돌하지 않습니다.

## 공용 계정 동기화 (구글 시트)

계정이 **이 기기에만** 있으면 피클·APK·카톡 인앱·삼성인터넷·크롬 중 어디로 열었는지에 따라 로그인 정보가 달라집니다.
그래서 아이디·비밀번호 해시·이름·결재 권한·품목 목록 열쇠(`kcat`)를 **구글 시트 한 곳**(`계정목록` 시트의 `portal_users` 행)에
같이 두고, 발주·업무일지·근태·포털 네 앱이 같은 계정 목록을 씁니다.

- 주소: `https://script.google.com/macros/s/AKfycbx8vtZ9wxfqwEUhuIC5hhV5dncN7IbVmrbjbPS93hfibfXAxMpwx-YtCGiqHeZXfEY81Q/exec`
  (`{"action":"users_get"}` 으로 읽고 `{"action":"users_save","usersJson":"…"}` 로 덮어쓰기)
- **올리는 것**: `{ v:1, updatedAt:"yyyy-MM-dd HH:mm:ss", kcat:"…", deletedIds:["…"], users:[{id,name,role,apprRole,salt,hash,hashes{…},active,mustChange,createdAt}] }`
  — `hash`는 앱마다 접두어가 달라(`wl1|`·`kd1|`·`att1|`·`p1|`) 한 사람의 네 앱 해시를 `hashes`에 함께 담습니다. **평문 비밀번호는 올리지 않습니다.**
- **불러오기**: 로그인 화면이 열리면 물론, **이미 로그인된 세션으로 앱을 열 때도** 조용히 한 번 `users_get`을 부르고(60초 스로틀·실패 무소음), 이 기기에 없거나 비밀번호가 안 맞으면 로그인 버튼을 눌렀을 때 한 번 더 시도한 뒤 비밀번호를 확인합니다. 시트가 이 기기보다 새로우면 그 계정 목록으로 맞춥니다.
- **이름·결재 권한 자동 반영**: 시트의 `name`·`role`·`apprRole`·`active`가 이 기기 계정과 다르면 로그아웃 없이 바로 바꿉니다.
- **사용자별 메뉴(`menus`)**: 포털 `사용자 관리`에서 정한 값을 시트로 받아 두기만 하고, 이 앱이 계정 목록을 올릴 때(전체 저장 포함) 시트 값을 그대로 남깁니다(`syncKeepSheetMenus`).
- `내 계정`의 `🔐 통합 포털` 버튼은 로그인한 사람이면 누구나 보이고, `?stay=1` 로 포털에 돌아가 자기 메뉴를 다시 고를 수 있습니다.
  앱 세션(`kdw.session.v1`)·통합 로그인 표시(`kd.portal.sso.v1`)의 이름·권한도 함께 바뀌고, 열린 일지의 **성명·담당자**가 이전 이름이었으면 새 이름으로 바뀌며 그 날짜·작성자 결재 건을 다시 붙입니다(이미 상신한 일지는 건드리지 않습니다).
- **지우기는 `deletedIds` 로만**: 관리자가 `삭제` 를 누른 아이디만 `deletedIds` 에 담아 올리고, 다른 기기는 **그 목록에 있는 계정만** 지웁니다.
  시트에 없다는 이유로 이 기기의 계정을 지우지 않고 **병합해 보존**합니다(다른 기기가 인원이 적은 목록을 올려도 이 기기의 계정이 사라지지 않음).
- **☁️ 이 기기 계정으로 전체 업데이트** (사용자 관리 · 관리자): 이 기기에 있는 계정 목록(결재 권한 포함)을 그대로 시트에 덮어써 다른 기기·앱을 이 기기 기준으로 맞춥니다(한 번 더 확인, `deletedIds` 도 비움).
- **올리기**: 관리자가 계정을 추가·수정(결재 권한)·삭제하거나 비밀번호를 재설정할 때, 그리고 내가 내 비밀번호를 바꿀 때 바로 `users_save` 합니다. 실패해도 이 기기 저장은 그대로 두고 다음에 다시 올립니다.
- **처음 채우기(씨앗)**: 시트가 비어 있을 때, 이 기기에 진짜 계정(2명 이상이거나 관리자 비밀번호를 바꾼 기기)이 있으면 그 계정을 올려 씨앗을 만듭니다. 처음 기본 `admin`만 있는 빈 기기는 올리지 않습니다.
- **같은 비밀번호면 어느 앱에서 만든 계정이든 열립니다**: 로그인에 성공하면 그 비밀번호로 네 앱 해시를 다시 만들어 시트에 맞춰 둡니다.
- **결재 건이 시트에서 지워졌을 때(유령 결재번호)**: 이 기기 일지에 남은 옛 결재번호가 이번에 받은 시트 목록에 없고, 같은 날짜·같은 작성자 행이 있으면 그 행의 **새 결재번호·상신 시각·본부장/대표 승인 상태**로 다시 붙입니다(옛 `03:29 본부장 대기` 같은 상태가 계속 남지 않음). 시트에 살아 있는 결재번호는 건드리지 않습니다.
- 시트가 안 열리거나 인터넷이 없으면 이 기기에 저장된 계정으로 그대로 로그인합니다(로그인 화면에 짧게 안내).

## 업무명·업무내용 시트 동기화

`오늘의 업무` 칩(업무명·업무내용)도 **계정별로 구글 시트에 보관**해 PC·스마트폰이 같은 칩을 씁니다.

- 고칠 때마다(업무명 추가·삭제, 업무내용 추가·삭제) **이 기기에 먼저 저장**하고 잠깐 뒤 `chips_save`로 올립니다.
- 로그인할 때와 앱으로 돌아올 때 `chips_get`으로 내 칩을 받아 오고, 시트가 더 최신이면 이 기기를 시트 기준으로 맞춥니다(받아 왔다는 안내).
- 시트에 아직 내 칩이 없고 이 기기에 사용자가 만든 칩이 있으면 그 칩을 시트에 **씨앗**으로 올립니다. **기본 칩 두 개만 있는 빈 기기는 올리지 않아** 다른 기기 칩을 덮어쓰지 않습니다.
- 저장 형식은 `계정목록` 시트의 `worklog_taskchips` 행 하나에 `{ byUser: { 아이디: { chips:[{name, items[]}], updatedAt } } }` — 계정 목록(`portal_users`)과 다른 행이라 서로 덮어쓰지 않고, `chips_save`는 **그 계정 것만** 갈아 끼웁니다.
- 시트가 안 되거나 인터넷이 없어도 이 기기 저장·편집은 그대로 됩니다.
- Apps Script를 새로 올릴 때는 `apps-script-approval.gs`를 편집기에 붙여 넣고 **[배포] → [배포 관리] → 연필(수정) → 버전 '새 버전' → [배포]** — 주소(`…/exec`)는 그대로입니다.
